ربط لوحة الإدارة بـ GitHub

الجدول محفوظ في مستودع الموقع على GitHub، والنشر يحتاج مفتاح وصول (توكن) مرة واحدة على هذا الجهاز.

  1. افتح صفحة إنشاء التوكن وسجّل دخول بحساب GitHub صاحب الموقع.
  2. تحت Repository access اختر Only select repositories ثم اختر .
  3. تحت Permissions اجعل Contents على Read and write.
  4. اضغط Generate token، انسخ التوكن والصقه هنا.

التوكن يُحفظ في هذا المتصفح فقط ولا يُرسل إلا إلى GitHub.
