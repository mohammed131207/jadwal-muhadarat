ربط النشر بـ GitHub (مرة وحدة)

هاي الخطوة بيعملها صاحب حساب GitHub مرة وحدة بس. بعدها أي حدا معه كلمة سر اللوحة بينشر من أي جهاز بدون توكن.

  1. افتح صفحة إنشاء التوكن وسجّل دخول بحساب GitHub صاحب الموقع.
  2. تحت Repository access اختار Only select repositories وبعدين .
  3. تحت Permissions خلّي Contents على Read and write.
  4. اضغط Generate token، انسخ التوكن والصقه هون.

التوكن بينحفظ بالموقع مشفّر بكلمة سر اللوحة، وصلاحيته محصورة بتعديل ملفات هالمستودع.
