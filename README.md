# جدول المحاضرات

موقع بسيط يعرض جدول المحاضرات حسب الدفعة، مع لوحة إدارة لإدخال المواعيد.

- **صفحة الطلاب:** https://mohammed131207.github.io/jadwal-muhadarat/
- **رابط مباشر لدفعة معيّنة:** أضف اسم الدفعة بعد `#`، مثل `.../jadwal-muhadarat/#2025`
- **لوحة الإدارة:** رابط «دخول الادمن» أسفل الصفحة، أو `.../jadwal-muhadarat/admin.html`

## طريقة الاستخدام

1. ادخل لوحة الإدارة بكلمة السر.
2. اختر الدفعة، وأضف المحاضرات (اليوم، من، إلى، المادة، والقاعة والمحاضر اختياريان).
3. التعديلات تنحفظ على جهازك كمسودة. تقدر تشوفها من «معاينة التعديلات».
4. اضغط **نشر التعديلات** لتظهر للطلاب (خلال دقيقة تقريباً).

أول مرة تنشر من أي جهاز، اللوحة بتطلب **توكن GitHub** وبتشرح خطوات إنشائه.
التوكن لازم يكون مقتصر على مستودع `jadwal-muhadarat` وصلاحية `Contents: Read and write`.

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `index.html` + `assets/app.js` | صفحة الطلاب |
| `admin.html` + `assets/admin.js` | لوحة الإدارة |
| `assets/common.js` | إعدادات المستودع وأدوات مشتركة |
| `assets/style.css` | التصميم |
| `data/schedule.json` | بيانات الجدول (اللوحة تعدّله تلقائياً عند النشر) |
