# جدول المحاضرات

موقع بيعرض جدول المحاضرات الأسبوعي، ومعه لوحة إدارة لإدخال المواعيد.

- **صفحة الطلاب:** https://mohammed131207.github.io/jadwal-muhadarat/
  بتفتح الجدول مباشرة: الأيام أعمدة والساعات صفوف، وكل مادة إلها لون.
  فوق الجدول في بطاقة بتبيّن المحاضرة الحالية أو الجاية، وبالضغط على أي محاضرة بتطلع تفاصيلها.
- **لوحة الإدارة:** رابط «دخول الادمن» أسفل الصفحة، أو `.../jadwal-muhadarat/admin.html`

## طريقة الاستخدام

1. ادخل لوحة الإدارة بكلمة السر.
2. اضغط **إضافة محاضرة**: اكتب اسم المادة (أو اختارها من المواد السابقة)، واختار اليوم وساعة البداية والمدة بالأزرار.
   زر **حفظ وضيف غيرها** بيجهّزلك المحاضرة اللي بعدها بنفس اليوم.
3. التعديلات بتنحفظ على جهازك كمسودة، وبتقدر تشوفها من «معاينة».
4. اضغط **نشر التعديلات** لتظهر للطلاب (خلال دقيقة تقريباً).

- **الحضور والملاحظة:** بنموذج المحاضرة بتختار إذا الحضور إجباري ولا لأ، وبتقدر تكتب ملاحظة. الطالب بيشوفهم بتفاصيل المحاضرة.
- **الكويزات:** من «إضافة كويز» بتختار المادة و**التاريخ** والوقت (إذا في محاضرة لنفس المادة بنفس اليوم، الوقت بيتعبّى لحاله).
  الكويز بيطلع بجدول الأسبوع اللي هو فيه، وبقائمة «الكويزات الجاية» فوق الجدول.
- **التعارض** ما بيمنع الحفظ؛ بتطلع نقطة حمرا مع تفاصيل التعارض.
- **روابط الزوم** لكل مادة من قسم «روابط الزوم»، ومعها وقت آخر تحديث.

عنوان الجدول والسطر الصغير فوقه (مثلاً «دفعة 2025») بتغيّرهم من «إعدادات الجدول».

### ربط النشر (مرة وحدة بس)
أول نشر بيطلب **توكن GitHub** من صاحب الحساب، واللوحة بتشرح خطوات إنشائه.
التوكن بينحفظ في `data/access.json` **مشفّر بكلمة سر اللوحة**، فبعدها أي مشرف معه كلمة السر بينشر من أي جهاز بدون توكن.
التوكن لازم يكون محصور بمستودع `jadwal-muhadarat` وصلاحية `Contents: Read and write`.

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `index.html` + `assets/app.js` | صفحة الطلاب (الجدول الأسبوعي) |
| `admin.html` + `assets/admin.js` | لوحة الإدارة |
| `assets/common.js` | إعدادات المستودع وأدوات مشتركة |
| `assets/style.css` | التصميم |

| `data/access.json` | توكن GitHub مشفّر (لا تعدّله بإيدك) |
